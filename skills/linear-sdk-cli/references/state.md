# linear state

> Inspect workflow states

Group alias: `st`

_Generated from `linear commands --json`. `linear state --help` (or `<subcommand> --help`) is authoritative._

Every command also accepts the global flags `-j/--json`, `--no-input`, `-y/--yes`, `-q/--quiet`, `--workspace <slug>`, `--api-key <key>`, `-t/--team <key>`, `-n/--limit <n>`, `--all`, `-f/--fields <a,b,c>`, `--no-ansi` (alias `--no-color`), and `--debug`. Only command-specific options are listed below.

### `linear state`

Inspect workflow states

Aliases: `st`

```
linear state [options]
```

### `linear state list`

List a team's workflow states (defaults to the configured team)

Aliases: `ls`

```
linear state list [options] [team]
```

### `linear state view`

Show a workflow state (by id)

```
linear state view [options] <id>
```
